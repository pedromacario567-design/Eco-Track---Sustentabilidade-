📌 Sobre o projeto

O EcoTrack é uma plataforma web fictícia desenvolvida para incentivar práticas sustentáveis e conscientizar as pessoas sobre a importância da preservação ambiental.

Através da plataforma, os usuários podem registrar atividades ecológicas, acompanhar seus resultados e acumular pontos por suas ações positivas em relação ao meio ambiente.

O projeto foi desenvolvido com finalidade educacional e para compor um portfólio de desenvolvimento web.

🎯 Objetivos
Incentivar hábitos sustentáveis.
Promover a reciclagem de materiais.
Estimular a economia de água.
Incentivar o plantio de árvores.
Demonstrar o impacto das pequenas ações ambientais.
✨ Funcionalidades
Painel de indicadores ambientais.
Registro de atividades sustentáveis.
Sistema de pontuação ecológica.
Armazenamento de dados com LocalStorage.
Interface responsiva.
Cadastro de usuários.
Integração com banco de dados.
Histórico detalhado de atividades.
